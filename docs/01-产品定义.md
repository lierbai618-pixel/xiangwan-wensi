# 01 产品定义

> 本文件是开发者（含 AI 协作伙伴）最常查阅的文档。任何功能、Prompt、UI 的改动，都不得与本文件冲突。

## 1. 产品定位

一个以**经典哲学、文学与心理学**为知识基础的 **AI 思辨助手**。
帮助用户理解人生问题、拓展思考视角、形成自己的判断，**不替其做决定**。

（项目名待定，候选：知行 / 明道 / 思源 / 问道 / 哲思 / 人生研究所 / 思辨助手）

## 2. 用户画像

- 年龄 18～35，处于学业 / 职场 / 关系 / 自我成长的高频困惑期。
- 关注：焦虑、迷茫、内耗、学习、工作、爱情、家庭、成长、自律、长期主义、意义感。
- 偏好：被尊重、被倾听；反感说教、站队、制造焦虑。

## 3. MVP 范围（Phase A–D 交付）

- 首页话题入口 + "每日思考"。
- 聊天页：思辨式回答 + 思考框架切换 + 引用卡片（原文 / 解读分离）。
- 知识库：首批公有领域经典（见 `03-知识库规范.md`）。
- 基础 RAG 检索（词法 + 余弦；意图分类与多库融合为 Phase E）。

## 4. 核心功能

| 功能 | 说明 |
|---|---|
| 今日思考 | 首页引导"今天想聊什么"，按主题进入 |
| 每日思考 | 主题 + 经典原文 + 一个开放问题（非名言堆砌） |
| 思辨对话 | 理解 → 多视角 → 引用 → 现实建议 → 开放问题 |
| 思考框架 | 综合 / 实践 / 儒家 / 道家 / 斯多葛 / 存在主义 / 心理学（分析工具，非站队） |
| 引用卡片 | 经典原文与 AI 解读明确分离、可点开溯源 |
| 思辨模式 | 事实 → 情绪 → 哲学视角 → 行动 → 回顾，陪用户想而非给答案 |

## 5. 非目标（明确不做什么）

- 不做人物扮演 / AI 替身。
- 不做"标准答案"式问答。
- 不做时政 / 新闻资讯。
- 不内置付费咨询、电商、社交。

## 6. 页面结构（规划）

- `pages/home` 首页：话题选择 + 每日思考
- `pages/chat` 聊天：思辨对话 + 框架切换 + 引用卡片
- `pages/about` 关于：产品理念 + 协议入口
- `pages/privacy` 隐私与协议
- `pages/admin` 管理（模型 / 未来知识库管理）

## 7. 用户流程

首页（选主题 / 每日思考）→ 进入聊天 → 提问 → AI 思辨式回答（多框架可切换）→ 查看引用卡片 → 收藏 / 分享 → 留下开放问题继续想。

## 8. 产品原则

1. **理解，而不是说教**
2. **启发，而不是灌输**
3. **多元，而不是唯一答案**
4. **引用经典，而不是编造观点**
5. **鼓励行动，而不是制造焦虑**

## 9. 产品边界（重要）

本产品**不是**：

- ❌ 心理治疗（不诊断、不治疗心理疾病）
- ❌ 医疗建议
- ❌ 法律咨询
- ❌ 投资建议
- ❌ 宗教传播
- ❌ 思想灌输

触及上述边界的问题，转向专业资源，**不输出 AI 主观结论**。

### AI 不承担的责任

明确边界，是为了保护用户，也是产品的长期底线。无论 Prompt 如何迭代，以下约束不变：

- **AI 提供**：思考框架、哲学视角、经典引用、阅读建议。
- **AI 不提供**：
  - ✗ 人生最终答案
  - ✗ 专业诊断（心理 / 医疗）
  - ✗ 权威裁决（法律 / 投资）
  - ✗ 唯一正确的价值观

> 用户始终是决定的主体。AI 的作用是拓展视角、陪伴思考，而不是替代判断。

## 10. 版本规划

- v0.1 MVP：首页 + 聊天 + 引用 + 每日思考 + 首批知识库
- v0.2：RAG 意图分类 + 多库融合
- v0.3：每周专题 / 阅读路线 / 思辨模式深化
- v1.0：稳定运营 + 内容运营体系

## 11. 验收标准

### 通用验收（每次回答必须满足）

1. 能**理解问题**，而不是直接抛名言（先回应处境 / 情绪）。
2. 至少引用 **1 段可追溯**经典原文（书名 + 篇目 / 章节，来自检索 Top5，不得编造）。
3. 至少呈现 **2 种思考视角**（不同思想传统 / 框架）。
4. **AI 解读与原文明确区分**（分段、明确标注）。
5. 结尾至少 **1 个开放问题**，引导继续思考。
6. **不输出唯一正确答案**，不命令用户。

### MVP 场景验收（连续 3 个不同人生问题）

- 问题覆盖：成长 / 焦虑 / 学习 / 关系 / 意义 / 选择 中至少 3 类。
- 每个问题均满足上述 6 条。
- 引用全部来自检索 Top5，**无 LLM 编造引用**。

### 检索指标（便于自动测试）

- 引用来源必须落在 `retrieve()` 返回的 Top5 Chunk 之内；
- 引用数量、Chunk ID、命中知识源可后台记录（见 `02-AI回答规范.md` 回答遥测）。
