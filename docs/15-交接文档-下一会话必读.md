## 3. 现在卡在哪（必须解决才能往前走）

### 🔴 卡点 1：会话列表页 `sessions.wxml` 在开发者工具里报 "not found"（当前会话最新问题）
- **现象**：聊天页点顶栏「会话」→ 跳转到 `/pages/sessions/sessions`，模拟器报错 `./pages/sessions/sessions.wxml not found`。
- **已排查的事实（非代码 bug）**：
  - 4 个页面文件**确实存在于磁盘**：`weapp/miniprogram/pages/sessions/{sessions.js,wxml,wxss,json}`。
  - `app.json` 第 9 行**已注册** `pages/sessions/sessions`。
  - `project.config.json` 的 `miniprogramRoot: "miniprogram/"` 正确。
  - 路径与注册完全匹配。
- **根因判断**：这些文件是 AI 通过文件系统直接落盘的，而**微信开发者工具启动时只扫描一次目录树并缓存**。运行期间新增的 `pages/sessions/` 目录对 DevTools 是"凭空出现"，它重新编译时能读到 `.json`/`.js`（注册路径匹配），但渲染 `.wxml` 时内存文件树里没有这个目录 → 报 not found。这是 DevTools 已知行为。
- **预期修复（无需改代码）**：在开发者工具里 **右键左侧文件面板 → 刷新**（或工具栏 🔄），等目录树出现 `pages/sessions/` 后点「编译」；若仍无效则「项目 → 重新打开此项目」。
- **回退排查路径（若刷新后仍报 not found）**：① 确认磁盘文件未被安全软件/杀软拦截；② 在 DevTools 里手动新建一个空 `sessions` 页面再覆盖内容，强制 DevTools 接管；③ 检查 `sessions.wxml` 是否有 DevTools 无法解析的字符（当前内容纯静态 view，应无问题）。

## 5. 踩过哪些坑（下一会话务必先看，避免重复踩）

1. **运行环境是 Node 16，不是 18+**（⚠️ 最高频坑）。用户原话"环境不可改变"。`chat/config.json` 写的 `runtime:Nodejs18.15` 不生效。所有云函数代码必须兼容 Node 16，**禁止原生 `fetch`**，必须走 `rag.js` 内置 `nodeFetch`（基于 Node 内置 https）。之前多份文档写的"确认 Node 18+"是错误指令，已作废。
2. **历史功能"不显示"的根因是部署漏项，不是缺代码**。`history` 云函数代码完整，但各阶段部署清单只让人部署了 chat/admin/feedback，漏了 `login`+`history` → 无 openid + history 调用失败 → 历史从没显示。排查时别急着改代码，先核对部署清单。
3. **"点击不了发送"是静默 no-op，不是事件绑定错**。多会话重构后 `send()` 在会话 ID 为空时依赖 `createConversation` 回调，而 history 未部署时回调空串 → 整个发送被吞。修复用本地兜底 ID 直接发。
4. **聊天页"整页闪烁"是前端渲染层，与云函数/Node 版本无关**。`typewriter` 每 18ms 全量 setData + `scroll-into-view` 在空/有效目标间反复。改 `scrollTarget` 初值 + 路径更新单条消息即可，别去动云函数。
5. **P0 前后端契约断裂**：`admin.js` 漏回填 `categoryBreakdown/feedback/quality`；`about.js` 反馈字段 `text` vs 云函数只读 `question`。这类"字段名对不上"的 bug 在小程序里很隐蔽（不报错只静默失败）。
6. **DevTools 文件树缓存**：在 DevTools 之外（AI 直接落盘 / 文件管理器）新增页面/组件，DevTools 不一定认，报 `xxx.wxml not found` 但文件其实在磁盘。**先刷新文件树 / 重新打开项目**，别急着改代码。
7. **微信云环境不是文件配置**：上传云函数报"请选择云环境"时，改 `project.config.json` 没用，必须用户在 IDE GUI 里开通/选中环境（见 MEMORY.md 关键约定）。
8. **合法域名漏配 = 真机静默失败**：模拟器勾了"不校验合法域名"能跑，真机不配 `api.hcnsec.cn` 就一直回退本地回答，表现像"模型没调"。
9. **集合不会自动建**：云数据库 `DATABASE_COLLECTION_NOT_EXIST` 必须手动建；首次保存模型报 `model_config` 不存在是常态。
10. **GBK 代码页坑**：测中文接口用 Python（`urllib`/`requests` 显式 `.encode('utf-8')`），别用 Git Bash `curl`（中文变乱码）。
11. **删文件/查进程用 Node/PowerShell**：`rm -rf`/`Remove-Item` 被 safe-delete 拦截；Git Bash `/proc` 不可靠。
12. **网页版是合规雷区，已归档**：旧 `maoxuan-assistant`（毛选语料 + "同志"称呼）与「问道」边界冲突且版权风险，已移至 `archive/maoxuan-assistant-legacy/`，**不要并入主线、不要发布**。
