# 00 项目愿景

> 本文件基本不会频繁修改，是产品所有决策的"北极星"。当具体功能与愿景冲突时，以愿景为准。

## 一、为什么做这个产品？

当代年轻人（18～35 岁）在面对学习、工作、亲密关系、家庭期待与人生选择时，普遍经历焦虑、迷茫与内耗。他们并不缺信息，缺的是**把信息转化成自己判断的思考框架**。

当下的内容环境，要么提供情绪刺激（短视频、热搜），要么提供"标准答案"（鸡汤、成功学），很少陪一个人**把问题想清楚**。而人类数千年积累的哲学、文学与心理学，恰好是一套经过时间检验、且多元互补的思考工具——但它们门槛高、零散、与现代生活脱节。

我们要做的，是一座桥：把经典里的思考方式，翻译成年轻人能在真实困境里用得上的视角。

## 二、为谁做？

- **核心用户**：18～35 岁、有自我觉察意愿但常被情绪与选择困住的年轻人。
- **典型状态**：在"该不该辞职""要不要继续一段关系""怎么面对父母的期待""努力有没有意义"之间反复拉扯。
- **他们不需要被说服，需要被带着一起想。**

## 三、希望用户得到什么？

不是答案，而是：

1. **更多视角**——同一个问题，儒家、道家、斯多葛、存在主义会怎么看。
2. **自己的判断**——在多元视角之后，由用户自己下结论。
3. **与情绪共处的方式**——理解情绪不是敌人，而是思考的起点。
4. **一个值得继续想的问题**——对话结束，思考不结束。

## 一句话愿景

> 用经典哲学、文学与心理学，帮助年轻人理解问题、拓展视角、形成自己的判断——而不是替他们做决定。
