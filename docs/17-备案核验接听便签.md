# 备案核验接听便签 · 向晚问思

> APPID：`wx2653f12589f9d89f`
> 用途：工信部/微信备案人工核验来电时，照此口径应答。全程与提交内容一致即可。

## 一、接电话前（1 小时内）
- 手机畅通，留意来电：**010 / 0755 / 020 等固话**，可能带「微信 / 腾讯」标记，**别当骚扰挂断**。
- 在手边备好：管理员本人身份证（报后几位即可）、提交时填的「服务内容」。

## 二、通话口径（照原样答，别临场改说法）
| 核验问项 | 应答 |
|---|---|
| 是否本人申请 | 是，本人操作 |
| 小程序名称 | 向晚问思 |
| 服务内容 | 工具-办公 / 生活服务（按你提交时填的选） |
| 用途 | 以经典哲学、文学、心理学为根基的 AI 思辨助手，陪用户理解问题、拓展视角、形成自己的判断 |
| 是否涉及前置审批项 | **无**（不涉及新闻、出版、广播、医疗、心理咨询、教育培训、宗教、网约车等） |
| 产品边界 | 不提供医疗诊断、心理咨询、教育培训、法律等专业服务，仅为思考辅助工具 |

## 三、漏接怎么办
- 一般当日还会再打 1–2 次，留意同一时段来电。
- 若一直未接到：进公众平台「备案系统」看是否可重新发起核验。

## 四、核验通过后
- 备案进入管局正式审核（通常 7–20 个工作日）。
- 期间**不受影响**仍可做：云函数部署、建集合、选云环境、真机测试。
- 只有「提交代码审核 + 发布」需等备案完成。
