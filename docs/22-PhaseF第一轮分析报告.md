## 五、用户价值问题（已可初步判断）

### 高价值征兆
- **迷茫类（50%）**用户用"我不知道"+"怎么办"组合表达 → 真实需要引导
- **复测 #16**（#19 复测）的回答 858 字 = 用户最长答案之一 → hotfix 解决了"想说很多但被截断"的问题
- **情绪/自我类**新问题（#17 #18）→ 用户**进入新主题**了，证明产品开始承载更深层对话

### 潜在空泛风险
- **追问未充分识别**：#11 "我总是在意别人怎么看我"被归"判断"，但实际属"自我"——分类边界仍模糊

- **citation_correct / useful 全为 null**（待人工核 + 用户反馈）→ 数据深度待补

### 需优化问题
- **追问链路未贯通**（#4 #5 "我还是不懂/太深奥了"是追问但 question_logs 独立记录）→ E-1 上下文记忆可能未生效（**不修**，记 Phase G）

- **孟子/大学召回稀疏**（2/20）→ user_questions 桥梁稀疏（**不补桥**，记 Phase G）
