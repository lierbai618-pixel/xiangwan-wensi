# 03 知识库规范

> 本规范解决"资料从哪来、能不能信、怎么切"的问题。当前项目最缺的就是它。

## 一、文档来源登记（强制）

每一份入库文本必须记录元数据：

| 字段 | 说明 |
|---|---|
| `title` | 作品名 |
| `author` | 作者 |
| `translator` | 译者（若有） |
| `edition` | 版本 |
| `publisher` | 出版社 |
| `year` | 出版年 |
| `copyright` | 版权状态（如：公有领域 / 已授权） |
| `license` | 授权协议（若有） |

**没有完整来源登记的文件，不得入库。** 这能杜绝来源不明文本混入。

## 二、版权与合规

- 优先使用**公有领域**作品（注意各国版权期限不同）。
- 受保护现代作品：确认授权，或使用公开可用的节选 / 评论资料。
- 译本有独立版权，使用公有领域译本或已授权译本。
- MVP 首批**不含**任何需时政类目资质的内容。

## 三、Chunk 原则

- **不跨章节**：切分尊重原文结构，不把一段意思劈成两半。
- **保留上下文**：父块（Parent）承载完整语境，子块（Child）用于精确检索。
- **引用可追溯**：每个 chunk 记录 `source_position`（书名·篇目·起止）。
- **不修改原文**：入库文本与原文件逐字一致，清洗只去版式噪声。

## 四、资料仓库与运行时分离

- `knowledge/`：原始资料仓库（按 Chinese / Western / Psychology / Literature 分类），**不参与运行**。
- `documents` + `chunks`：ingest 后的运行时数据，由 `knowledge/` 生成。

```
knowledge/          ← 原始资料（人工维护、可审计）
  Chinese/
  Western/
  Psychology/
  Literature/
      ↓ ingest
documents / chunks  ← 运行时检索数据
```

## 五、MVP 首批清单（建议，控制在 20 本以内）

> 知识库越小，RAG 越容易调优；先验证产品价值，再扩源。

- **中国哲学（6）**：论语、孟子、大学、中庸、道德经、庄子
- **西方哲学（4）**：沉思录（马可·奥勒留）、爱比克泰德《手册》、柏拉图《申辩篇》（公有领域译本）、亚里士多德《尼各马可伦理学》（节选，公有领域文本）
- **文学（2，优先公有领域；现代作品确认译本授权后再纳入）**：小王子、悉达多
- **心理学（1，版权谨慎）**：《活出生命的意义》（弗兰克尔）——若无合适授权，MVP 阶段暂不纳入全文，改用公开书评 / 节选资料

合计约 13 本，均在 20 本上限内，且优先使用公有领域或已授权内容。

> MVP **暂不**纳入任何需时政类目资质的内容；待产品稳定、合规路径清晰后再评估扩源。
